## Sobre mim

Supervisiono o time de Integrações API na Diretoria de Novos Negócios da SIEG Soluções. Tenho mais de 10 anos de experiência em liderança de equipes e operações de atendimento. Antes de assumir Integrações, liderei o Onboarding da Regional Sul em Customer Success.

Essa trajetória orienta o que desenvolvo e estudo. Uso Python, JavaScript, SQL e APIs para explorar problemas que conheço da operação, como investigar falhas de integração, automatizar tarefas recorrentes e explicar por que um indicador mudou. Em IA, meu foco é avaliar se um agente consegue usar as fontes disponíveis, reconhecer quando faltam informações e respeitar os limites do seu escopo.

## Como desenvolvo

- **Começo por um cenário verificável.** Defino o que o projeto precisa fazer e como reproduzir o resultado.
- **Trabalho em incrementos pequenos.** Uso agentes de código para apoiar a implementação e reviso as mudanças com base no comportamento esperado.
- **Automatizo a verificação.** Cada funcionalidade nova tem um teste de comportamento. Cada bug corrigido ganha um teste de regressão que reproduz a falha.
- **Facilito a execução.** Cada projeto tem seu próprio repositório, com instruções para rodar, exemplos com dados sintéticos e testes no CI quando aplicável.
